# SimlyDent Workspace

Workspace phục vụ kỳ thực tập Full-stack Developer, bắt đầu từ **03/08/2026**.

## Cấu trúc

- `internship-log/`: nhật ký, kế hoạch, task, kiến thức và báo cáo thực tập.
- `projects/`: nơi clone từng repository mã nguồn công ty.
- `playground/`: code thử nghiệm và bài tập không chứa dữ liệu công ty.
- `resources/`: tài liệu công khai hoặc được phép lưu trữ.

> Không lưu token, mật khẩu, dữ liệu khách hàng hoặc thông tin nội bộ nhạy cảm trong workspace này.
