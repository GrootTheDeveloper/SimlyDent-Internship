# Vue 2 Examples

1. `PatientPicker.vue`: Single-File Component nhỏ, thể hiện `v-model`, `v-if`, `v-for`, props, computed và `$emit`.
2. `PatientFilter.vue`: custom `v-model` theo quy ước `value` prop + `input` event.
3. `PatientList.vue`: ví dụ bổ sung về Options API, bảng/form/phân trang BootstrapVue và `$set`; không được dùng trong PDF.

PDF sử dụng `PatientPicker.vue`; component này độc lập và không dùng biến chưa khai báo.
