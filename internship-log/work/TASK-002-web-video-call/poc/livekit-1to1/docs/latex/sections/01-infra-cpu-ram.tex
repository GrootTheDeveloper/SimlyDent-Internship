\subsection{Ghi chú đọc số liệu}

CPU LiveKit trong bảng chịu tải là mẫu giữa mỗi mức (\texttt{docker stats}). RAM LiveKit
là bộ nhớ container SFU, không gồm process \texttt{lk} load-test trên host. Load CLI chạy
cùng VPS với SFU. Một cuộc gọi camera thật không được ghi CPU host theo giây.
