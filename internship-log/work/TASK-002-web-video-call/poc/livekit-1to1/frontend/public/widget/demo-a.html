Nha khoa Demo A

Trang giả lập website phòng khám (clinic-a / pk_clinic_a)

Widget SimlyDent được nhúng bằng một thẻ <script>. Bấm nút gọi góc phải để tạo cuộc gọi queue.

Origin: trang này phải nằm trong allowlist EMBED_ORIGINS_CLINIC_A hoặc EMBED_PUBLIC_ORIGIN. Staff mở portal, login A1/A2, Accept cuộc gọi.

Trang này cùng origin với portal nếu mở trên host SimlyDent — chỉ demo UI. Multi-origin thật: chạy .\scripts\serve-embed-demo-origins.ps1 -ApiBase https://YOUR_DOMAIN -ProbeAndServe (port 5174/5175 = website PK giả; widget load từ YOUR_DOMAIN). Xem docs/phase2-browser-e2e-protocol.md.
