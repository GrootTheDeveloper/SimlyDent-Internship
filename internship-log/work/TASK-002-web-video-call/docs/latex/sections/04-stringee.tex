\section{Sàng lọc giải pháp triển khai}

Điều kiện khảo sát gồm mã nguồn và giấy phép công khai, khả năng self-host signaling và
media, hỗ trợ WebRTC trên web và không phụ thuộc cloud của nhà cung cấp. Hoạt động của
kho mã nguồn phản ánh trạng thái duy trì. Độ ổn định production cần kết quả qualification
và dữ liệu vận hành.

Jitsi gồm web app, Jitsi Videobridge, Jicofo và Prosody
\cite{jitsi-repo,jitsi-architecture}. OpenVidu Community phân phối API tương thích
LiveKit; multi-node và high availability thuộc edition thương mại
\cite{openvidu-docs}. Element Call sử dụng MatrixRTC và LiveKit. MiroTalk và Nextcloud
Talk là ứng dụng giao tiếp hoàn chỉnh \cite{element-call,mirotalk,nextcloud-talk}. Pion
cung cấp WebRTC API ở cấp thư viện để xây media server \cite{pion-repo}.

Stringee và các API truyền thông theo mô hình managed service không đạt điều kiện
self-host và bị loại khỏi ma trận PoC.
