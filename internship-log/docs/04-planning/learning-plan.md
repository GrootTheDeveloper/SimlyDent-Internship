# Kế hoạch học tập

| Chủ đề | Lý do cần học | Tài nguyên | Thực hành qua task | Trạng thái |
|---|---|---|---|---|
| Kiến trúc dự án | Hiểu phạm vi thay đổi | Tài liệu nội bộ |  | Chưa bắt đầu |
| Git workflow | Làm việc an toàn với team | Convention của team |  | Chưa bắt đầu |
| Testing | Giảm lỗi và tự xác minh | Test suite dự án |  | Chưa bắt đầu |

## Nguyên tắc

- Ưu tiên kiến thức trực tiếp phục vụ task.
- Mỗi nội dung học cần có ghi chú hoặc minh chứng thực hành.
- Cuối tuần đánh giá lại kế hoạch dựa trên blocker và feedback.
