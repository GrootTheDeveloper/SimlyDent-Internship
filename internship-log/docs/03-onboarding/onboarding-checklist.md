# Onboarding Checklist

## Tài khoản và quyền truy cập

- [ ] Email/tài khoản công ty
- [ ] Công cụ giao tiếp
- [ ] Công cụ quản lý task
- [ ] Git repository
- [ ] Môi trường development/staging
- [ ] Tài liệu nội bộ

## Môi trường phát triển

- [ ] Clone repository cần thiết
- [ ] Cài runtime và dependency
- [ ] Tạo cấu hình local an toàn
- [ ] Chạy được frontend
- [ ] Chạy được backend
- [ ] Kết nối được database local/dev
- [ ] Chạy được test/linter

## Kiến thức dự án

- [ ] Hiểu sản phẩm và luồng chính
- [ ] Hiểu cấu trúc repository
- [ ] Hiểu quy trình Git/PR/review
- [ ] Hiểu cách nhận và cập nhật task
- [ ] Biết cách báo cáo blocker
