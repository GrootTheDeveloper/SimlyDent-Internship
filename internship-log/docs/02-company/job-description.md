## Sản phẩm và phạm vi công việc

- Tham gia xây dựng và tối ưu hệ thống ERP quản lý phòng khám nha khoa trên nền tảng web.
- Phát triển backend API bằng .NET/C# và làm việc trực tiếp với PostgreSQL.
- Xây dựng frontend bằng Vue 2 + BootstrapVue, tập trung vào form, bảng dữ liệu, báo cáo, modal và responsive.
- Phân tích yêu cầu, đề xuất giải pháp kỹ thuật và cải thiện trải nghiệm người dùng tại phòng khám.
- Fix bug, tối ưu query/code và refactor module cũ để hệ thống ổn định, dễ bảo trì.
- Phối hợp với QA, BA, UI/UX và team triển khai.

## Năng lực kỹ thuật được kỳ vọng

### Backend — .NET/C#

- C#, .NET/.NET Core, OOP và `async/await`.
- Web API và kiến trúc Controller → Service/Business → Repository.
- DTO, mapping, input validation và exception handling.

### Database — PostgreSQL

- SQL: join, group by, subquery, view và index cơ bản.
- Nhận biết và hạn chế N+1; chọn index hợp lý; đọc execution plan ở mức cơ bản.
- Thiết kế bảng với primary key, foreign key, constraint và kiểu dữ liệu phù hợp.

### Frontend — Vue 2 + BootstrapVue

- Làm việc thực tế với Vue 2.
- Dùng BootstrapVue cho table, form, modal, pagination và filter.
- Thành thạo `v-model`, props, emit, tách component và tránh lặp code.
- Biết viết component tái sử dụng.

### Quy trình và tư duy

- Git: branch, pull request, merge và xử lý conflict.
- Code rõ ràng, gọn, dễ đọc; comment có mục đích.
- Phân tích nguyên nhân gốc thay vì chỉ xử lý triệu chứng.
