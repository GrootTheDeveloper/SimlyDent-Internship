# Điều hướng

| Khu vực | Nội dung |
|---|---|
| `01-profile` | Thông tin, năng lực và mục tiêu cá nhân |
| `02-company` | Công ty, sản phẩm, team và thuật ngữ |
| `03-onboarding` | Môi trường, repository, kiến trúc và quy trình |
| `04-planning` | Roadmap, kế hoạch học tập và milestones |
| `05-worklog` | Nhật ký ngày và tổng kết tuần |
| `06-tasks` | Hồ sơ vòng đời từng task |
| `07-knowledge` | Ghi chú kỹ thuật theo chủ đề |
| `08-decisions` | Các quyết định kỹ thuật quan trọng |
| `09-meetings` | Biên bản và action items từ cuộc họp |
| `10-feedback` | Feedback, code review và tự đánh giá |
| `11-final-report` | Báo cáo và tổng kết cuối kỳ |
